## 📖 项目简介
本项目是基于 Web 的 2D 巡检机器人仿真。用户可以在网页端查看 10x10 的二维地图，通过按钮或键盘控制机器人移动，并实时观察坐标和状态反馈。

## 🚀 运行说明
本项目已通过 Docker 容器化。
启动命令：`docker compose up -d`
访问地址：`http://localhost:5000`

## 👥 团队分工

本项目严格参照社团培训大纲，团队成员分别在嵌入式、运维、全栈、人工智能四个方向做出了核心贡献：

*   **嵌入式与具身智能（温文静）**：
    负责机器人的“本体”与底层物理逻辑。在 `app.py` 中构建了机器人的运动学模型，实现了坐标更新、边界碰撞检测以及**虚拟传感器**模块（负责采集四周障碍物信息并返回异常报警状态）。同时负责项目的整体架构统筹与最终验收。
*   **人工智能（[马骁腾]）**：
    负责机器人的“大脑”规划与 AI 辅助开发。在二维栅格地图中，纯手写实现了 **A*（A-Star）启发式寻路算法**，支撑了自动巡检功能；并利用大语言模型辅助进行代码审查与异常处理逻辑设计。
*   **全栈开发（[梁志聪]）**：
    负责系统的“皮囊”与交互。基于 HTML5 Canvas 完成了二维地图的动态渲染，使用 JavaScript 实现了键盘控制、按钮交互以及后端 API 的 Fetch 数据通信，完成了前后端联调。
*   **运维与部署（[黎展锦]）**：
    负责项目的工程化落地。编写 Dockerfile 与 Compose 文件，将项目打包为 `linux/amd64` 的公开镜像并推送至阿里云 ACR 仓库；同时配置了 GitHub Actions 基础 CI，保障代码质量。

前端 (HTML5 Canvas) <--> HTTP请求 <--> 后端 (Flask API)
部署：Docker 容器化 | 镜像仓库：阿里云 ACR
